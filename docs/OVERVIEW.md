# Overview

## The Problem

Small online sellers in India (Instagram, WhatsApp, basic websites) spend hours every day on:
- Manual order tracking and status updates
- Stock checks across variants
- Customer messages (many repetitive)
- Fraudulent Cash-on-Delivery (COD) orders and Return-to-Origin (RTO) abuse

Existing AI and operations tools target large retailers. Small sellers need affordable help while staying in control of every decision.

## The Solution (One Paragraph)

Shiro is an e-commerce platform with a built-in AI agent team for small Indian sellers. The platform has three layers: a customer-facing **Storefront**, an owner-only **Admin Panel**, and an **Agent Team** that handles daily operations. Agents **suggest** actions (flag suspicious orders, draft replies, propose restocks), the human **decides** (approve/reject via admin panel or Telegram), and the **Audit Agent** records every decision for accountability. The demo business is a home seller selling toys (~150 orders/month, mainly Instagram), with a violet and off-white theme.

## Core Loop

```
Agent suggests → Human decides → Audit Agent records
```

## What Shiro Is NOT

- A fully autonomous "AI runs your business" system — human approval is required for every important action
- A replacement for your storefront — it includes one, but you can swap the theme
- A generic chatbot — agents are specialized, auditable, and tied to your data
- A first-of-its-kind multi-agent system — the pattern exists; our angle is small-seller, India-specific, human-approved, auditable, low-cost
- Built yet — this is **Planning / Pre-alpha**
